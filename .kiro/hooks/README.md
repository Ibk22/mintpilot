# Kiro hooks

Kiro agent hooks for MintPilot will live in this directory as the build
progresses (for example, hooks that run checks when spec or contract files
change).

This directory is intentionally present from the first commit: the Kiroween
2026 rules require a `/.kiro` directory at the repo root, and hooks are one
of its expected parts alongside `specs/` and `steering/`.
